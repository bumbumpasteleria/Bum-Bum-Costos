# Recetas completas y borradores clasificados

Cuando una fórmula no indica porciones, se puede registrar el rendimiento **1 receta completa**. Representa toda la fórmula; media receta es 0.5 y el doble es 2. No equivale a una porción ni inventa piezas vendibles. Si el documento declara un rendimiento, se conserva.

Los borradores se guardan dentro del recetario elegido. Buscar borrador y Categoría de borradores permiten localizarlos. Cada categoría comienza cerrada. Abre Qué falta revisar para ver ingredientes sin identificar, cantidades o instrucciones pendientes.

En el editor se conserva la expresión original de cada ingrediente y el texto del documento. Las observaciones deben revisarse y resolverse antes de confirmar la receta definitiva; una casilla registra esa revisión. Las líneas incompletas siguen sujetas a la validación de ingredientes, cantidades y unidades. Guardar borrador conserva la revisión y el documento en la cuenta.

No se convierten tazas, cucharadas, gotas ni latas sin una equivalencia confirmada. Una alternativa de ingredientes requiere elegir el artículo. Las etapas organizan ingredientes sin duplicarlos. Los documentos privados y fórmulas no forman parte del código público.
